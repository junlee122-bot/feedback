# 과외 제안서 작성

학생 요청서를 읽고, `profile.md`에 있는 사실만으로 그 학생에게 맞춘 제안서를 씁니다. 답은 한국어로 합니다.

## 1. 프로필 확인

- 저장소 루트의 `profile.md`를 읽는다.
- 사용자가 김과외 프로필 캡처나 텍스트를 주면, 거기 있는 내용으로 `profile.md`의 `(작성 필요)` 항목을 채운다. 화면에 없는 항목은 그대로 둔다. 저장소가 공개이면 실명·연락처·주소는 넣지 않는다. 채운 뒤 이 세션이 끝나면 사라지니 커밋해서 남길지 사용자에게 묻는다.
- 학력·과목·경력·수업 방식이 아직 `(작성 필요)`이면, 제안서를 쓰기 전에 김과외 프로필 캡처나 텍스트를 보내 달라고 한 번 묻는다. 사용자가 프로필 없이 바로 원하면, 프로필이 필요한 자리는 `[ ]` 빈칸으로 남기고 쓴다.
- 프로필에 없는 경력·학력·실적·숫자는 절대 지어내지 않는다.

## 2. 요청서 읽기

캡처에서 아래 항목을 뽑는다. 화면에 없는 항목은 "확인 안 됨"으로 두고 추측으로 채우지 않는다.

- 과목
- 학년·학교
- 현재 수준 (등급, 점수, 모의고사 성적)
- 목표 (목표 대학·학과, 목표 점수)
- 수업 목적 (기초, 내신, 파이널 등)
- 장소·방식
- 학생 성향·특이사항
- 요청사항 (기간, 지금 듣는 강의, 원하는 선생님 조건)
- 선생님 조건 (학력, 성별 등)

캡처가 여러 장이면 먼저 같은 요청서의 이어지는 화면인지, 서로 다른 학생인지 판단한다. 학교·과목·수준이 다르면 다른 학생으로 보고 학생마다 따로 쓴다.

과목이 화면에 직접 안 보이면 내용으로 추론하되(예: "한국사 2등급" → 한국사 내신) 추론이라고 표시한다.

## 3. 맞춤 포인트 정하기

제안서가 복사·붙여넣기한 글처럼 보이지 않게 하는 단계다. 쓰기 전에 정한다.

- 학생이 가장 원하는 것 한 가지 (예: 인강 글쓰기 개별 첨삭, 기말 전 4주 완성)
- 그 요구와 맞닿는 내 프로필의 사실 2~3개
- 다시 언급할 요청서 속 구체적 숫자·이름 (목표 학교, 점수, 기간, 지금 듣는 강의)
- 학생이 원하는 조건 중 내 프로필에 없는 것 (예: 특정 강사 커리 수강 경험). 있는 척하지 않고, 대신 할 수 있는 것을 정직하게 제시한다 (예: "수강 중인 커리 교재와 과제에 맞춰 첨삭").
- 성향·말투 요청 (예: "상처받게 말하지 않는 분") → 제안서 안에서 수업 태도로 답한다.

## 4. 제안서 쓰기

모바일에서 읽기 좋게 짧은 문단으로 쓴다.

1. 인사와 한 줄 소개 (호칭, 핵심 이력 하나)
2. 요청서를 읽었다는 증거: 학생의 상황과 목표를 요청서 표현 그대로 짧게 짚기
3. 왜 나인지: 맞춤 포인트 2~3개 (프로필의 사실 근거)
4. 수업 계획: 기간이 정해져 있으면 주차별(예: 4주 → 1~4주차), 아니면 단계별(기초 → 실전 → 파이널). 학생이 말한 목적과 기간에 맞춘다.
5. 진행 방식: 첨삭·피드백·숙제 관리 (프로필의 수업 방식 기준)
6. 마무리: 상담이나 첫 수업 제안, 정중한 인사

원칙:

- 분량은 본문 600~1,000자 안팎. 길이보다 구체성을 우선한다.
- "1등급 보장", "100점 만들어 드립니다" 같은 성적·합격 보장 표현은 쓰지 않는다. 계획과 방법으로 신뢰를 준다.
- 필요한데 프로필에 없는 정보는 `[ ]` 빈칸으로 두고 '보내기 전 확인'에 적는다.
- 학생 정보는 요청서에 있는 범위에서만 쓴다.
- 말투는 `profile.md`의 '말투·스타일'을 따른다. 비어 있으면 정중하고 따뜻한 존댓말, 이모지 없음.
- "귀하의 자녀분" 같은 템플릿 문구 대신 요청서의 표현을 쓴다.

## 5. 출력 형식

학생마다 아래 순서로 낸다.

**요청서 요약** — 2단계 항목을 짧은 목록으로. 확인 안 됨·추론 표시 포함.

**제안서** — 본문 전체를 `text` 코드블록에 넣어 휴대폰에서 한 번에 복사할 수 있게 한다.

**보내기 전 확인**
- `[ ]` 빈칸과 채워야 할 내용
- 요청서에서 확인되지 않아 제안 전에 정하면 좋은 것 (수업료, 요일, 주 몇 회 등)
- 첫 상담 때 물어볼 질문 2~3개

마지막에 "더 짧게 / 더 격식 있게 / 수업료 넣어서" 같은 수정 요청을 받을 수 있다고 한 줄로 안내한다.
