# feedback

과외 선생님을 위한 Claude Code 스킬 모음입니다. 사진이나 메모를 보내면 피드백과 제안서를 대신 써 줍니다.

| 스킬 | 이렇게 말하면 실행돼요 | 하는 일 |
| --- | --- | --- |
| `/lesson-feedback` | "피드백 써줘", "첨삭해줘" | 수업 메모로 학부모님께 보낼 수업 피드백을 쓰거나, 학생 글·답안 사진을 첨삭 |
| `/tutor-proposal` | "제안서 써줘" + 요청서 캡처 | 김과외 학생 요청서를 읽고 내 프로필에 맞춘 제안서 작성 |

## 내 피드백 스타일

수업 피드백은 실제로 보낸 피드백 64건을 분석한 [`style.md`](.claude/skills/lesson-feedback/style.md)대로 씁니다. 회차 제목, 📌·📚 섹션, 활동마다 교육적 이유를 붙이는 합니다체, 숙제 공지와 맺음 문장까지 따라 써요. 공개 저장소라서 예시의 학생 이름과 학교는 모두 바꿨습니다. 실제 피드백 원문은 앱 프로필의 "내 피드백 예시" 칸에 넣으면 내 계정에만 저장됩니다.

## 아이폰 앱으로 쓰기

[`app/tutor-helper.html`](app/tutor-helper.html)은 같은 기능을 휴대폰 화면에 맞춘 개인용 웹앱입니다. claude.ai 비공개 아티팩트로 게시돼 있고, 내 Claude 계정으로 동작하기 때문에 API 키가 필요 없어요.

- 탭은 제안서, 피드백, 첨삭, 기록, 프로필 다섯 개입니다.
- 프로필과 기록은 내 계정에만 저장돼서 다른 기기에서도 그대로 보여요.
- Safari에서 앱 주소를 열고 공유 → **홈 화면에 추가**를 누르면 앱처럼 쓸 수 있어요.

## 처음 한 번: 프로필 채우기

제안서는 [`profile.md`](profile.md)에 적힌 내용만 근거로 씁니다. 없는 경력은 지어내지 않고 `[ ]` 빈칸으로 남겨요.

- 직접 채우기: `profile.md`의 `(작성 필요)` 자리를 고치면 됩니다.
- 캡처로 채우기: 김과외 내 프로필 화면을 캡처해서 "프로필 채워줘"라고 보내면 Claude가 채워 줍니다.

> ⚠️ 이 저장소는 현재 **공개(public)** 입니다. 프로필에 실명·연락처는 적지 말고, 가능하면 GitHub 저장소 설정에서 비공개(private)로 바꿔 주세요. 학생 요청서 캡처나 학생 글은 저장소에 올리지 않습니다.

## 사용 예시

**제안서**
> (요청서 캡처 첨부) 제안서 써줘

캡처가 여러 장이고 서로 다른 학생이면 학생마다 따로 써 줍니다. 요청서 요약, 바로 복사할 수 있는 제안서 본문, 보내기 전 확인할 것 순서로 나와요.

**수업 피드백**
> 피드백 써줘. 한국사 3회차, 조선 전기 정치 끝냄. 단원 퀴즈 16/20, 붕당 순서 헷갈림. 숙제: 교과서 85~92쪽 정리, 기출 20문항

**첨삭**
> (학생 논술 답안 사진 + 논제 사진) 첨삭해줘. 상처받지 않게, 하지만 현실적으로

## 참고

- Claude Code(앱, 웹, 터미널)에서 이 저장소를 열면 스킬이 자동으로 잡힙니다. 새 세션은 기본 브랜치(`main`)를 가져오므로, 이 브랜치를 `main`에 합쳐야 다음 세션부터 쓸 수 있어요.
- 스킬 내용을 바꾸고 싶으면 `.claude/skills/<스킬 이름>/SKILL.md`를 고치면 됩니다.
